# 权限中心 V3 → V4 切换

本文档记录 `paasng.infras.iam` 从权限中心 V3 迁移到 V4 的整体形态与推进顺序。

## 切换形态

V4 不提供 Python SDK，能力全部经 HTTP 提供，网关名由 `bk-iam` 变为 `bkiam`。V3 与 V4 的授权数据完全隔离，因此版本由 `BK_IAM_VERSION` 按**部署环境**整体决定，不支持模块级或应用级混用。

## 代码分层

- `base/`：`BaseAuthBackend` / `BaseManagementBackend` 抽象接口与 DTO，两版实现共同遵循
- `shim.py`：按配置分发，`get_auth_backend()` / `get_management_backend()` 是上层唯一入口，各版本实现延迟导入
- `v3/`、`v4/`：各版本具体实现。`v4/registry.py` 负责模型注册，`v4/http.py` 封装翻页（单页上限 100）与批量分批（单次上限 20）

## 推进顺序

1. **契约先行**——`#1` 客户端基座与双版本开关。产出 `base/` 抽象与 `v4/` HTTP 骨架，是其余子需求的依赖基线。
2. **并行实现**——`#2` 权限模型 V4 注册与幂等同步、`#3` 鉴权判定、`#4` 列表策略下推、`#5` 管理空间、`#6` 用户组与成员管理、`#7` 资源回调与申请链接。
