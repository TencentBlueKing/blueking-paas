# V1.7.0 版本更新日志
### 新增
- 多租户环境下，创建应用时可选择租户，成员选择使用新版组织架构选择器，并内置环境变量 `BKPAAS_APP_TENANT_ID`。该环境不提供 ESB API 申请。
- 支持在开发者中心创建代码仓库并指定分组。开发沙箱支持自定义环境变量、增强服务、Go 和免密登录。
- 环境变量支持密码类型和脱敏展示。挂载卷支持子路径、Secret 和自定义容量。
- 平台管理可配置云原生应用资源配额，描述文件可引用这些方案，内存配额增加 16G、32G。云原生应用可按集群设置节点选择和污点容忍。
- 同一个 S-mart 包可创建多个应用，可按不同基础镜像构建，并提供打包工具和构建过程。
- 平台支持子路径访问。自定义访问地址支持多级路径和 HTTPS。
- 云 API 权限使用新版网关，可设为永久有效，过期后可直接续期。支持申请 MCP Server 权限，申请记录可打开审批链接。
- 增强服务解绑后可暂不回收，应用内和平台管理均可手动回收，方案可克隆。平台管理可彻底删除应用。本地资源池支持精确或模糊匹配。
- Redis 增强服务支持哨兵模式。MySQL 增强服务按更严格的规则生成密码。
- 应用分类位于基本信息，部署前必填。创建应用提供示例目录。内置 AI 插件模板，AI 插件应用可改为源码部署。
- 代码仓库部署的云原生应用，可在进程配置页查看和修改进程，并设置停止前等待时间。
- 首页展示已收藏的应用及其部署状态。
- 使用保留前缀创建应用时需验证授权码。验证码可通过短信发送。

### 优化
- 应用概览补充访问统计，并整理统计图表。设置市场地址后，列表中的生产环境地址显示该地址。
- 自定义访问地址不能使用平台保留域名。本地增强服务不能与已有远程增强服务同名。
- 日志保存和存储可按环境配置，也可使用日志平台的共享采集项。ES 集群可按租户配置。子路径访问不提供访问日志。
- 文档链接随界面语言切换。内置环境变量可配置多条和不同前缀，并标明能否被应用覆盖。
- 平台管理可维护应用模板，集群详情可查看节点，隐藏配置可一次展开或收起。
- 代码仓库密码提交时加密传输。升级依赖和基础镜像，提升平台安全性。

### 修复
- 彻底删除应用后再次创建，不再残留旧的权限数据。
- bkrepo 增强服务可分配给其他租户的应用。
- 子路径部署时，管理端后台可正常使用。应用成员可正常添加，自定义访问地址可打开。
- 发布环境变量后，部署历史中的耗时正确。S-mart 应用可进入控制台。
- 未开启 TLS 时，MySQL 增强服务和已预留实例可正常分配。无重启记录时，查看重启日志会给出说明。
- 从 1.5 升级到 1.7 时，操作审计可完成迁移。通过链接上传源码包时，只接受允许的地址。
- 普通应用的进程资源只读展示，调整仍走原有页面。
