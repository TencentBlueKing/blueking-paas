# V1.8.0 版本更新日志
### 新增
- 提供 Agent 沙箱，支持隔离沙箱和 E2B 沙箱。同租户应用可共享存储并管理沙箱文件。沙箱到期自动清理，单个应用有数量上限，删除存储时一并清理对应目录。
- 平台管理可登记沙箱模板，并查看、执行运维命令。支持创建 AI Agent 应用，上传源码包时可选择构建方式。
- AppSpark 支持新建项目、按描述生成项目、对话、按轮选择模型、预览，并发布到开发者中心。项目可重命名，删除时清理相关资源。
- 权限中心可切换到 V4，支持同步权限模型、管理用户组和成员、管理空间，以及迁移已有权限。
- 平台和应用的敏感配置可从密钥管理服务加载，默认关闭。应用可开启敏感环境变量加密。
- 构建镜像可通过镜像代理拉取基础镜像。应用构建可打开调试模式。
- 云 API 权限申请可取消或删除，申请记录可复制审批链接。可按应用查看调用流水和告警记录。
- 绑定 Redis 增强服务的模块会配置告警。Redis 补充配置项、环境变量模板和哨兵说明，支持按实例调整配额并查看指标。
- RabbitMQ 增强服务支持 stream，方案可按集群标签选择集群。
- 社区版初始化时注册权限管理和模块部署的 MCP Server。插件中心可单独开关权限同步。
- 内置环境变量增加 `BKPAAS_NODEMGR_URL`。云 API 网关和 MCP Server 补充了供应用调用的系统接口。

### 优化
- 读取裸 Git 分支时，只拉取分支和标签指向的提交。日期选择使用统一样式。
- 创建应用时，示例目录和镜像构建提示中的路径按文本展示。
- 社区版网关默认按具体资源授权。构建工具更新为 Go v238、Python v358、Node.js v375。
- 沙箱预览直接打开沙箱地址，创建时待沙箱就绪后再返回。Redis 内存使用率按容器内存上限计算。

### 修复
- 平台管理中编辑增强服务方案时，已填配置会保留。构建参数留空时仍可提交部署。
- 权限中心切换到 V4 后，授权、成员和权限模型同步仍可正常使用。管理端后台页面可正常打开。
- 初始化外链应用时，已存在的应用 ID 会跳过，不中断初始化。
- RabbitMQ 增强服务可完成升级。BKRepo 增强服务可按配额正常分配。
- 进程配置展示的资源配额与当前方案一致。

### 变更
- 数据库类型环境变量由 `BK_DATABASE_TYPE` 改为 `BKPAAS_DB_TYPE`。
- 已使用 Agent 沙箱文件存储且未单独配置制品桶时，默认桶名有变化。若需沿用原桶，配置为 `agent-sandbox-artifacts`。新部署不受影响。
- 新部署默认使用 heroku-24 基础镜像。已指定默认镜像的环境不变。
